# REVIVE 5.0

Free local-first full-stack prototype for rural healthcare visibility.

## Features
- User and Pharmacy login
- Pharmacy manual medicine inventory entry
- Medicine, bed, blood and organ availability
- Deterministic Smart Referral engine (specialty + bed capacity + distance)
- English / Tamil UI
- Working internal Back button and browser history
- Express REST API
- JSON persistence on the local machine
- IndexedDB-ready offline cache layer
- Browser-native voice can be added without a paid AI API
- No Gemini API key required

## Demo login
User: `user@revive.demo` / `revive123`
Pharmacy: `pharmacy@revive.demo` / `revive123`

## Run
`npm install`
`npm run dev`
Open `http://localhost:3000`.

This is a prototype/demo and not a clinical decision-making system.
